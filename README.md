# Shelf Label Designer — releases

Installers and updates of **Shelf Label Designer**. The source code is private.

**Install:** open [Releases](../../releases/latest), download `Shelf-Label-Designer-Setup-<version>.exe` and run it. Windows may show "Windows protected your PC" because the installer is not code-signed: choose **More info → Run anyway**.

Installed apps update themselves: from the main PC on the local network, or from here.
